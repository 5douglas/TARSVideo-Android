# Historical VLC experiment

This directory contains files from an earlier experimental TARSVideo build
that integrated VLC Android components.

These files are preserved for historical/reference purposes only.

They are **not part of the current TARSVideo Android build pipeline**.

Current TARSVideo releases use the native Jellyfin/ExoPlayer playback path.

The accompanying `VLC-GPL-NOTICE` must remain with this historical source
because the VLC Android code is subject to the applicable VideoLAN/GPL terms.
